# 📝 Simple To-Do List (Command Line App)

This is a basic Python to-do list that runs in the terminal. You can:

- ✅ Add tasks
- 📋 View tasks
- ❌ Delete tasks

## 🚀 How to Run

1. Make sure you have Python installed
2. Run the app with:

```bash
python todo.py


Then save it.

## 📂 Add a .gitignore File

This file tells Git what **not** to upload (temporary or system files).

### 1. In VS Code, click "New File" → name it `.gitignore`  
(make sure there’s a **dot** at the beginning)

Paste this in:

```bash
# Ignore macOS system files
.DS_Store

# VS Code settings folder
.vscode/

# Python cache folders
__pycache__/
*.pyc
